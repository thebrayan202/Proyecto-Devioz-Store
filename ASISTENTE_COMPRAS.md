# Asistente de compras

Abre `asistente_compras.php` desde el menú de tu tienda.
Para instalar en hosting, activar IA y cargar el futuro catálogo de Plaza Vea,
sigue `HOSTING_Y_CATALOGOS.md`.

Incluye modo básico, conexión API opcional, presupuesto, reserva para gastos,
catálogos por tienda/sede e importación JSON desde el panel administrativo.
Plaza Vea queda pendiente de datos reales. No hay compras externas automáticas.
